# Experiment 02 – Overloading

This experiment covers the concept of function overloading, operator overloading, and friend functions in C++.

## Programs

1. Complex number addition and subtraction using operator overloading
2. Function overloading for different data types
3. Finding the maximum using a friend function
4. Adding five meters using a friend function
5. Finding areas using function overloading
6. Unary operator overloading

## Language

C++
